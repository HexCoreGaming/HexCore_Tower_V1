# V6.0.42 — Dashboard management expansion

- GitHub fine-grained token access unchanged.
- Dashboard now edits shared department information OR site-specific department overrides.
- Predefined AI guide dialogue text editable via the dashboard; action trees are not editable.
- Media placement selection (gallery, department display, featured) and independent site visibility.
- Draft content preview, posts and NPC Q&A remain editable.
- Public pages read site overrides. The 3D guide and traditional guide read managed dialogue copy.
- Public alpha label: **Alpha Version: 1.0.1**.

## Boundaries
The supported editors do not move 3D geometry, create entirely new pages, edit physical architecture, or implement a visual game editor. GitHub publishing requires a real authorized repository token and GitHub Pages deployment. No live GitHub integration was tested in this packaging environment.
