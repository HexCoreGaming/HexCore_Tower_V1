# V6.0.40 — traditional holographic command interface

Adds a separate presentation layer in `src/holo-command.css` and a scripted guide in `src/holo-command.js` exclusively to `holographic.html`.

The guide has clickable choices for all seven public departments, posts, galleries and 3D entry; no language model, sound or data collection.

Existing posts, media gallery, department content, dashboard, 3D world and NPC systems remain untouched.

This is a browser-based holographic interaction layer, not true volumetric holography.
