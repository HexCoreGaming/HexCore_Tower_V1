# HexCore Tower V14 — Separated Interior + Monument Tower Pass

## V14
Tall newly modeled spires, layered tower facade, prominently placed H emblem, purple-blue trims, monumental gateway, landscaping, water panels, a large planet and cosmic details. Exterior and lobby are now separated spaces. The lobby uses a concealed airlock-style exit, and the exterior is its own dedicated tower-plaza scene. Department floors, single portal per floor, controls, and legal Q&A preserved.

This is a mobile-focused procedural geometry interpretation of the approved reference image, not a photorealistic match. No old world model was imported.
