# HexCore Tower V2.0 — Exterior Match Pass

## Exterior
Reconstructed the tower front, all four facades, platform, purple and blue architecture, illuminated HEXCORE crest, elevated rings, landscaping, waterfalls off the floating platform edges, black polished plaza and stars/nebula/planets in a separate exterior 3D environment. No airlock or corridor was introduced. The lobby remains independently sized. Its sliding entrance is the only visible entrance element.

## Preserved
Original 41 Legal Q&As unchanged, all department floors and question placeholders retained, single destination portal per floor, mobile and desktop controls retained. Scene transition at doorway preserves yaw and pitch; browser live testing has not been completed.

## Deploy in GitHub Desktop
Extract ZIP. Copy **the contents** to the root of your HexCore_Tower_V1 repository. Commit to main and Push origin. Check V2.0 on the website's entry screen and HUD.

## Realism limits
This is an optimized playable 3D reconstruction from reference images, not pixel-for-pixel rendering of those images. Waterfall visuals are static mesh effects in this version; polished floor uses materials rather than real reflection probes. A browser and mobile playtest is still required.

- Entrance plaza kept flush with the building; disconnected stairs removed
