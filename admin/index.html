Administrator sign-in

Sign in with a GitHub fine-grained personal access token that has Contents: Read and write permission for your repository. GitHub verifies your credentials; this page does not contain a password or store your token.

GitHub Pages alone cannot securely validate the temporary password you provided. That password is intentionally not embedded. GitHub authorization is required for publishing. Use a token with access restricted to this repository and revoke it when done.
